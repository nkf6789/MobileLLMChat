# MobileLLMChat

## 项目简介
一个支持豆包API和本地大模型的Android聊天应用

## 功能特性
- [ ] 集成豆包云端API
- [ ] 支持本地大模型推理
- [ ] 多轮对话管理
- [ ] 聊天记录本地持久化

## 技术栈
- Kotlin
- Jetpack Compose / XML
- MVVM架构
- Retrofit（网络请求）
- Room（本地数据库）

## 开发环境
- Android Studio Hedgehog | 2023.1.1+
- Kotlin 1.9.0+
- Gradle 8.0+
- Min SDK: 24 (Android 7.0)
- Target SDK: 34 (Android 14)
